<summary><b>More about Content Compare Juxtapose plugin (click to expand)</b></summary>

**Juxtapose** is a content plugin for comparing two images in Joomla articles (3/4/5/6) by dragging a slider left and right. Perfect for **BEFORE** | **AFTER** effects.

**Features:**
* Easy to use directly inside Joomla articles
* Smooth slider for image comparison
* Compatible with Joomla 3, 4, 5, and 6
* Fully responsive on all devices

**How to use:** `{juxtapose}img_1.jpg|img_2.jpg{/juxtapose}`

<summary><b>More about MarkItUp Editor Lite plugin (click to expand)</b></summary>

**MarkItUp Editor Lite** – a simple, reliable, and ultra-lightweight HTML editor without external dependencies (about 2 KB of Vanilla JS, no jQuery required).

Designed for quick HTML editing in Joomla 4/5/6 – without TinyMCE or JCE, without switching between visual and source modes, and without auto-formatting your code.

Works in both the admin panel and the frontend. It can be attached to specific fields via CSS selectors and URL triggers.

**Advantages:**
* **HTML Safety:** Does not clean, reformat, or modify code automatically.
* **No mode switching:** Always works with clean HTML.
* **Joomla 4/5/6 compatibility:** Does not depend on specific core APIs or third-party libraries.
* **Lightweight:** ~2 KB Vanilla JS, no jQuery.

**Summary:** A small tool for quick and safe HTML editing where a full visual editor only gets in the way.

<details>
<summary><b>More about LazySpoiler plugin (click to expand)</b></summary>

**LazySpoiler** is a content plugin for Joomla 4/5/6 that creates interactive spoilers (collapsible blocks) with lazy image loading. Images inside the spoiler are loaded only when it is opened, which speeds up initial page load and saves user traffic.

**Features:**
* Full integration with Bootstrap 5 classes
* Customizable color, size, and animation speed in admin panel
* Smooth animation for opening/closing
* Responsive design for all devices
* Performance: minimal styles, no external CSS/JS
* Joomla update notifications

**How to use:**
`{spoiler title="Click to expand"}Content{/spoiler}`
*(Also supports `{details}` and `{SPOILER}` tags for backward compatibility)*

**Links:**
* [Download & Documentation](https://vodkomotornik.ru/runduk/download/12-poleznoe/92-lazyspoiler-plugin-joomla.html)

</details>

<details>
<summary><b>More about FancyBox Gallery plugin (click to expand)</b></summary>

**FancyBox Gallery** is a simple, lightweight, and flexible solution for creating responsive image galleries in Joomla 3.10+, 4, 5, and 6 articles directly from image folders.

The plugin automatically generates optimized WebP previews, integrates with FancyBox 5 for lightbox viewing, and offers flexible display settings.

**Features:**
* **Auto-optimization:** Generates lightweight WebP thumbnails on the fly.
* **Supported formats:** jpg, jpeg, png, gif, webp, bmp, avif.
* **FancyBox 5:** Modern lightbox with gestures, swipes, and responsive navigation.
* **Flexible controls:** Configure thumbnail count, sizes, and display modes (grid, button, counter, or dots).
* **SEO & Performance:** Lazy loading, async decoding, valid semantic markup (`<figure>`, `<figcaption>`).
* **Easy captions:** Support for `labels.txt` to sort images and add unique ALT/TITLE attributes.
* **Native integration:** Uses standard Joomla 4/5/6 Bootstrap 5 classes without bloating the template with extra CSS.
* **Update notifications:** Automatically checks for new versions in the Joomla admin panel.

**Important note:** The archive contains **2 versions** — for Joomla 3.10 (v1.2.1) and the current one for Joomla 4/5/6. Unzip and choose the one you need.

**Links:**
* [Download & Documentation](https://vodkomotornik.ru/runduk/download/12-poleznoe/991-fancybox-gallery-plugin-joomla-download.html)

</details>
